# VPD-1 : Virtual Phase Distortion Synth

VPD-1 is a wavetable + phase distortion synth that gives you full
control to create custom and unique morphing phase distortion shapes. 

For any questions, feedback, or join our discord server at: https://discord.gg/jsPZuS2n7c

This project is based on:
 - Wavetable by Roland Rabien: https://github.com/FigBug/Wavetable
 - Gin molude library for JUCE by Roland Rabien: https://github.com/figbug/gin
 - The Pamplejuce template by Sudara: https://github.com/sudara/pamplejuce
 - The JUCE framework: https://juce.com/
